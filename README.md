# BugBot测试示例代码

这个仓库包含故意编写的有问题的代码，用于测试Cursor BugBot的代码审查功能。

## 📁 文件说明

### `app.py` - Python Web应用示例
包含以下类型的问题：
1. **安全漏洞**
   - 硬编码敏感信息
   - SQL注入漏洞
   - XSS跨站脚本攻击
   - 未验证的用户输入

2. **资源管理问题**
   - 文件资源泄露
   - 内存效率问题

3. **逻辑错误**
   - 无限循环可能性
   - 除零错误
   - 空异常处理

4. **安全最佳实践违反**
   - 不安全的随机数生成
   - 生产环境debug模式

### `script.js` - JavaScript前端示例
包含以下类型的问题：
1. **安全漏洞**
   - DOM XSS攻击
   - 不安全的eval使用
   - 原型污染风险
   - 缺少CSRF保护

2. **性能问题**
   - 内存泄露
   - DOM查询优化问题
   - 同步XMLHttpRequest

3. **逻辑错误**
   - 竞态条件
   - 无限递归
   - 类型强制转换问题

4. **最佳实践违反**
   - 全局变量污染
   - 缺少错误处理
   - 不安全的数据存储

## 🤖 如何使用BugBot测试

1. **提交代码到GitHub**
   ```bash
   git add .
   git commit -m "Add problematic code for BugBot testing"
   git push origin main
   ```

2. **创建Pull Request**
   - 在GitHub上创建一个新分支
   - 修改代码（比如修复一些问题）
   - 创建Pull Request

3. **触发BugBot**
   - BugBot会自动运行并分析代码变更
   - 或者在PR评论中输入 `bugbot run` 手动触发

4. **查看结果**
   - BugBot会在发现问题时留下评论
   - 评论包含详细的问题说明和修复建议
